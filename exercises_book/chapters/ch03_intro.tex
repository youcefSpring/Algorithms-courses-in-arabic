\begin{tbox}{\faLightbulb\quad تعريفات}
\begin{itemize}
    \item \textbf{الحلقة التكرارية}: تعيد تنفيذ مجموعة تعليمات ما دام شرط ما محققًا.
    \item \code{for}: عندما يكون \textbf{عدد التكرارات معروفًا} مسبقًا (تهيئة؛ شرط؛ تحديث).
    \item \code{while}: الشرط يُختبر \textbf{قبل} كل دورة، فقد لا تُنفذ الحلقة أبدًا.
    \item \code{do ... while}: الشرط يُختبر \textbf{بعد} الدورة، فتُنفذ \textbf{مرة واحدة على الأقل}.
    \item \textbf{المجمِّع والعداد}: متغير يُهيأ قبل الحلقة (\code{sum = 0}، \code{count = 0}) ويُحدَّث داخلها.
\end{itemize}
\end{tbox}
