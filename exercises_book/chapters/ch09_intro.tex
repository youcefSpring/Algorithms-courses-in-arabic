\begin{tbox}{\faLightbulb\quad تعريفات}
\begin{itemize}
    \item \textbf{الهيكل} \code{struct}: نوع جديد يجمع \textbf{حقولًا} من أنواع مختلفة تصف كيانًا واحدًا (منتج، زبون، طلبية).
    \item \textbf{التعريف}: \code{typedef struct \{ int code; double price; \} Product;}
    \item \textbf{الوصول إلى الحقل} بالنقطة: \code{item.price}، وفي هيكل متداخل: \code{order.client.name}.
    \item \textbf{الإسناد} \code{copy = item;} ينسخ كل الحقول، بما فيها الجداول الداخلية.
    \item \textbf{التعداد} \code{enum}: أسماء لقيم صحيحة ثابتة (\code{PENDING}، \code{PAID}، ...).
\end{itemize}
\end{tbox}
