\begin{tbox}{\faLightbulb\quad تعريفات}
\begin{itemize}
    \item \textbf{البنية الشرطية}: تنفذ مجموعة تعليمات \textbf{فقط إذا} تحقق شرط (\code{if}).
    \item \textbf{البديل}: \code{else} ينفذ عندما يكون الشرط خاطئًا، و\code{else if} يسمح بسلسلة من الحالات.
    \item \textbf{الاختيار المتعدد}: \code{switch} يقارن متغيرًا صحيحًا أو حرفًا بقيم ثابتة (\code{case}) و\code{break} ينهي الحالة.
    \item \textbf{الشرط}: تعبير منطقي قيمته \en{1} (صحيح) أو \en{0} (خطأ)، يُبنى بـ \code{== != < <= > >=} ويُركب بـ \code{\&\& || !}.
\end{itemize}
\end{tbox}
