title: مصفوفة الارتباط
level: medium
domain: ds
@ statement
لثلاث خصائص لكل زبون (الزيارات، الدقائق، المبلغ) اكتب برنامجًا يحسب **مصفوفة الارتباط** `corr[3][3]` حيث `corr[a][b]` معامل بيرسون بين الخاصيتين، باستعمال الجذر بطريقة نيوتن.
@ steps
- نحسب متوسط كل عمود.
- `cov[first][second] = Σ (x - mean)(y - mean)`.
- `corr = cov[first][second] / جذر(cov[first][first] * cov[second][second])`.
@ flow
do: means = متوسط كل عمود
for: first = 0 ; first < 3 ; first++
  for: second = 0 ; second < 3 ; second++
    do: cov[first][second] = Σ (x - mean)(y - mean)
for: first = 0 ; first < 3 ; first++
  for: second = 0 ; second < 3 ; second++
    do: corr = cov[f][s] / جذر(cov[f][f] * cov[s][s])
    out: corr
@ code
#include <stdio.h>

#define NB 6
#define NB_FEAT 3

int main(void) {
    double data[NB][NB_FEAT] = {{3, 12, 1500}, {8, 40, 5200}, {5, 22, 2400},
                                {1,  4,  300}, {9, 50, 6100}, {4, 25, 1900}};
    double mean[NB_FEAT] = {0}, cov[NB_FEAT][NB_FEAT], product, root;
    int row, first, second, step;
    for (row = 0; row < NB; row++)
        for (first = 0; first < NB_FEAT; first++)
            mean[first] += data[row][first] / NB;
    for (first = 0; first < NB_FEAT; first++)
        for (second = 0; second < NB_FEAT; second++) {
            cov[first][second] = 0;           // التغاير (دون القسمة على n)
            for (row = 0; row < NB; row++)
                cov[first][second] += (data[row][first] - mean[first])
                                    * (data[row][second] - mean[second]);
        }
    for (first = 0; first < NB_FEAT; first++) {
        for (second = 0; second < NB_FEAT; second++) {
            product = cov[first][first] * cov[second][second];
            root = product;                   // الجذر بطريقة نيوتن
            for (step = 0; step < 60; step++)
                root = (root + product / root) / 2;
            printf(" %6.3f", cov[first][second] / root);
        }
        printf("\n");
    }
    return 0;
}

title: مصفوفة المسافات بين الزبائن

domain: ds
@ statement
اكتب برنامجًا يحسب **مصفوفة المسافات** `dist[5][5]` (مربع المسافة الإقليدية) بين 5 زبائن ممثلين بخاصيتين، مستغلًا **التناظر** `dist[a][b] = dist[b][a]` لحساب نصف الخانات فقط، ثم يجد أقرب زوج.
@ steps
- القطر أصفار.
- لكل `first < second`: نحسب المسافة ونكتبها في الخانتين.
- نحتفظ بأصغر مسافة.
@ flow
for: first = 0 ; first < NB ; first++
  do: dist[first][first] = 0
  for: second = first + 1 ; second < NB ; second++
    do: dist[first][second] = dist[second][first] = (dx² + dy²)
    if: dist < bestDist
      do: bestDist = dist ; pairA = first ; pairB = second
out: dist, pairA, pairB
@ code
#include <stdio.h>

#define NB 5

int main(void) {
    double points[NB][2] = {{2, 1.5}, {8, 6}, {3, 2}, {9, 7.5}, {5, 3}};
    double dist[NB][NB], dx, dy, bestDist = -1;
    int first, second, pairA = 0, pairB = 0;
    for (first = 0; first < NB; first++) {
        dist[first][first] = 0;
        for (second = first + 1; second < NB; second++) {   // النصف العلوي فقط
            dx = points[first][0] - points[second][0];
            dy = points[first][1] - points[second][1];
            dist[first][second] = dist[second][first] = dx * dx + dy * dy;
            if (bestDist < 0 || dist[first][second] < bestDist) {
                bestDist = dist[first][second];
                pairA = first;
                pairB = second;
            }
        }
    }
    for (first = 0; first < NB; first++) {
        for (second = 0; second < NB; second++)
            printf("%7.2f", dist[first][second]);
        printf("\n");
    }
    printf("Closest customers: %d and %d\n", pairA, pairB);
    return 0;
}

@ statement
نموذج يصنف التعليقات إلى 3 أصناف (0 سلبي، 1 محايد، 2 إيجابي). لدينا جدولا القيم الحقيقية والمتنبأ بها لـ 15 تعليقًا. اكتب برنامجًا يبني **مصفوفة الالتباس** `confusion[actual][predicted]` ويحسب **الدقة** (مجموع القطر / الكل).
@ steps
- نهيئ المصفوفة بأصفار.
- لكل تعليق: `confusion[actual[index]][predicted[index]]++`.
- الدقة = الأثر / عدد التعليقات.
@ flow

for: index = 0 ; index < NB ; index++
  do: confusion[actual[index]][predicted[index]]++

@ code
#include <stdio.h>

#define NB 15
#define NB_CLASSES 3

int main(void) {
    int actual[NB]    = {2, 0, 1, 2, 2, 0, 1, 1, 2, 0, 2, 1, 0, 2, 1};
    int predicted[NB] = {2, 0, 2, 2, 1, 0, 1, 0, 2, 0, 2, 1, 1, 2, 1};
    int confusion[NB_CLASSES][NB_CLASSES] = {{0}};
    int index, row, col, correct = 0;
    for (index = 0; index < NB; index++)
        confusion[actual[index]][predicted[index]]++;   // الفهرسان من الجدولين
    printf("actual\\pred  neg neu pos\n");
    for (row = 0; row < NB_CLASSES; row++) {
        printf("%11d", row);
        for (col = 0; col < NB_CLASSES; col++)
            printf(" %3d", confusion[row][col]);
        printf("\n");
        correct += confusion[row][row];   // القطر = التنبؤات الصحيحة
    }
    printf("Accuracy = %d/%d = %.2f\n", correct, NB, (double)correct / NB);
    return 0;
}
