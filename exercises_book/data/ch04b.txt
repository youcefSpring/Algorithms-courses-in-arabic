title: جمع أعداد ضخمة
level: medium
domain: ds
@ statement
رقم الأعمال السنوي لمنصة كبيرة يتجاوز سعة `long long`. نخزن العدد في **جدول من الأرقام** (الآحاد في الخانة 0). اكتب برنامجًا يجمع عددين من 25 رقمًا بخوارزمية الجمع المدرسية مع الاحتفاظ.
@ stdin
9876543210987654321098765
1234567890123456789012345
@ steps
- نقرأ كل عدد حرفًا بحرف بـ `scanf(" %c")` ونحول `ch - '0'`.
- نخزن معكوسًا: الحرف الأول هو أعلى رقم.
- لكل موضع: `sum = numA[pos] + numB[pos] + carry`، الرقم `sum % 10` والاحتفاظ `sum / 10`.
@ flow
in: numA, numB  (25 رقمًا)
do: carry = 0
for: pos = 0 ; pos < DIGITS ; pos++
  do: sum = numA[pos] + numB[pos] + carry
  do: result[pos] = sum % 10 ; carry = sum / 10
do: result[DIGITS] = carry
out: result معكوسًا
@ code
#include <stdio.h>

#define DIGITS 25

int main(void) {
    int numA[DIGITS], numB[DIGITS], result[DIGITS + 1];
    int pos, sum, carry = 0;
    char digit;
    for (pos = DIGITS - 1; pos >= 0; pos--) {     // الآحاد في الخانة 0
        scanf(" %c", &digit);
        numA[pos] = digit - '0';      // تحويل الحرف إلى رقم
    }
    for (pos = DIGITS - 1; pos >= 0; pos--) {
        scanf(" %c", &digit);
        numB[pos] = digit - '0';
    }
    for (pos = 0; pos < DIGITS; pos++) {
        sum = numA[pos] + numB[pos] + carry;
        result[pos] = sum % 10;       // الرقم المكتوب
        carry = sum / 10;             // الاحتفاظ للموضع التالي
    }
    result[DIGITS] = carry;
    pos = (carry > 0) ? DIGITS : DIGITS - 1;   // نتجاهل الصفر البادئ
    printf("Sum = ");
    for (; pos >= 0; pos--)
        printf("%d", result[pos]);
    printf("\n");
    return 0;
}

title: أطول فترة صعود في جدول
level: medium
domain: ds
@ statement
اكتب برنامجًا يجد في جدول أسعار سهم شركة تجارة إلكترونية **أطول فترة متصلة** من الارتفاع المتتالي، ويعرض فهرسي بدايتها ونهايتها وقيمها.
@ steps
- `start` بداية الفترة الحالية.
- إذا لم يكن `price[index] > price[index - 1]` تبدأ فترة جديدة عند `index`.
- إذا كان طول الفترة الحالية `index - start + 1` أكبر من الأفضل نحفظها.
@ flow
do: start = 0 ; bestStart = 0 ; bestLen = 1
for: index = 1 ; index < NB ; index++
  if: price[index] <= price[index - 1]
    do: start = index
  if: index - start + 1 > bestLen
    do: bestLen = index - start + 1 ; bestStart = start
out: bestStart, bestLen
@ code
#include <stdio.h>

#define NB 12

int main(void) {
    double price[NB] = {50, 52, 51, 53, 55, 58, 60, 57, 59, 61, 62, 60};
    int index, start = 0, bestStart = 0, bestLen = 1;
    for (index = 1; index < NB; index++) {
        if (price[index] <= price[index - 1])
            start = index;                    // الصعود انقطع
        if (index - start + 1 > bestLen) {
            bestLen = index - start + 1;
            bestStart = start;
        }
    }
    printf("Longest rise: index %d to %d (%d values):",
           bestStart, bestStart + bestLen - 1, bestLen);
    for (index = bestStart; index < bestStart + bestLen; index++)
        printf(" %.0f", price[index]);
    printf("\n");
    return 0;
}

title: الدرجة الموزونة للمنتج
level: medium
domain: ds
@ statement
لترتيب نتائج البحث نعطي كل منتج **درجة** = الجداء السلمي بين جدول خصائصه (التقييم، المبيعات المطبعة، الهامش، التوفر) وجدول **الأوزان** `{0.4, 0.3, 0.2, 0.1}`. اكتب برنامجًا يحسب درجات 4 منتجات ويعرض الأفضل.
@ steps
- الخصائص في جدول أحادي واحد: المنتج `product` خصائصه من `product * 4` إلى `product * 4 + 3`.
- الدرجة: `Σ weights[feat] * features[product * 4 + feat]`.
- نحتفظ بالأفضل.
@ flow
do: best = 0 ; bestScore = -1
for: product = 0 ; product < NB ; product++
  do: score = 0
  for: feat = 0 ; feat < 4 ; feat++
    do: score += weights[feat] * features[product*4 + feat]
  out: product, score
  if: score > bestScore
    do: bestScore = score ; best = product
out: best
@ code
#include <stdio.h>

#define NB 4
#define NB_FEAT 4

int main(void) {
    double weights[NB_FEAT] = {0.4, 0.3, 0.2, 0.1};
    // كل 4 قيم متتالية = منتج: تقييم، مبيعات، هامش، توفر (بين 0 و 1)
    double features[NB * NB_FEAT] = {0.90, 0.40, 0.30, 1.0,
                                     0.70, 0.95, 0.50, 1.0,
                                     0.85, 0.60, 0.80, 0.0,
                                     0.60, 0.30, 0.90, 1.0};
    double score, bestScore = -1;
    int product, feat, best = 0;
    for (product = 0; product < NB; product++) {
        score = 0;
        for (feat = 0; feat < NB_FEAT; feat++)
            score += weights[feat] * features[product * NB_FEAT + feat];
        printf("Product %d: score %.3f\n", product, score);
        if (score > bestScore) {
            bestScore = score;
            best = product;
        }
    }
    printf("Top result: product %d\n", best);
    return 0;
}
