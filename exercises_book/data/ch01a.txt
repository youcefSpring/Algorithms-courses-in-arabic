    notes500 = money / 500;  money = money % 500;    // أوراق 500
    notes200 = money / 200;  money = money % 200;    // أوراق 200

title: ساعة وصول الطلبية
level: medium
domain: ec
@ statement
تُسجَّل طلبية في الساعة `hour:minute` ويستغرق توصيلها `delay` دقيقة. اكتب برنامجًا يحسب **ساعة الوصول** بصيغة 24 ساعة، حتى لو تجاوزت منتصف الليل.
@ stdin
22 35 150
@ steps
- نحول وقت الطلب إلى دقائق منذ منتصف الليل: `total = hour * 60 + minute + delay`.
- ساعة الوصول: `(total / 60) % 24`.
- الدقائق: `total % 60`.
- نستعمل `%02d` لعرض صفر على اليسار.
@ flow
in: hour, minute, delay
do: total = hour * 60 + minute + delay
do: ah = (total / 60) % 24
do: am = total % 60
out: ah:am
@ code
#include <stdio.h>

int main(void) {
    int hour, minute, delay, total, ah, am;
    scanf("%d %d %d", &hour, &minute, &delay);
    total = hour * 60 + minute + delay;       // الدقائق منذ منتصف الليل
    ah = (total / 60) % 24;       // % 24 تعيد الساعة بعد 23 إلى 0
    am = total % 60;              // الدقائق
    printf("Arrival time: %02d:%02d\n", ah, am);
    return 0;
}

title: مدة الاشتراك بالأسابيع
level: medium
domain: ec
@ statement
يشترك زبون في خدمة توصيل مجاني لمدة `days` يومًا. اكتب برنامجًا يعرض هذه المدة بالأسابيع والأيام، وعدد الأشهر التقريبية (شهر = 30 يومًا) مع الأيام المتبقية.
@ stdin
200
@ steps
- الأسابيع: `weeks = days / 7` والأيام: `days % 7`.
- الأشهر: `mo = days / 30` والأيام: `days % 30`.
@ flow
in: days
do: weeks = days / 7 ; rw = days % 7
do: mo = days / 30 ; rm = days % 30
out: weeks, rw, mo, rm
@ code
#include <stdio.h>

int main(void) {
    int days, weeks, rw, mo, rm;
    scanf("%d", &days);
    weeks = days / 7;   rw = days % 7;      // أسابيع كاملة + أيام
    mo = days / 30; rm = days % 30;     // أشهر تقريبية + أيام
    printf("%d days = %d weeks + %d days\n", days, weeks, rw);
    printf("%d days = %d months + %d days\n", days, mo, rm);

}
