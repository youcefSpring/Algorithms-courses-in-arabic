@ stdin

@ steps
- العدد 2 أولي؛ ثم نختبر الأعداد الفردية فقط `number = 3, 5, 7, ...`.
- لكل `number`: حلقة داخلية على القواسم الفردية `divisor` ما دام `divisor * divisor <= number`.
- نتوقف عند أول قاسم (`isp = 0`).
@ flow
in: limit
do: count = 1 ; sum = 2
for: number = 3 ; number <= limit ; number += 2
  do: isp = 1 ; divisor = 3
  while: isp && divisor * divisor <= number
    if: number % divisor == 0
      do: isp = 0
    do: divisor += 2
  if: isp
    do: count++ ; sum += number
out: count, sum
@ code
#include <stdio.h>

int main(void) {
    int limit, number, divisor, isp, count = 0, sum = 0;
    scanf("%d", &limit);
    if (limit >= 2) {                     // 2 هو العدد الأولي الزوجي الوحيد
        printf("2 ");
        count = 1; sum = 2;
    }
    for (number = 3; number <= limit; number += 2) {     // الأعداد الفردية فقط
        isp = 1;
        for (divisor = 3; isp && divisor * divisor <= number; divisor += 2)
            if (number % divisor == 0)
                isp = 0;              // له قاسم: ليس أوليًا
        if (isp) {
            printf("%d ", number);
            count++;
            sum += number;
        }
    }

}

title: التجميع بـ K-Means في بعد واحد
level: hard
domain: ds
@ statement
نريد تقسيم 20 زبونًا إلى **مجموعتين** حسب إنفاقهم بخوارزمية **K-Means**. الإنفاق مولَّد بصيغة: `spend(customer) = (customer * 37) % 50 + (customer % 2) * 60` لـ `customer` من 0 إلى 19 (لا نخزنها، نعيد حسابها). نبدأ بمركزين `c1` و`c2` مقروءين ونكرر: نسند كل نقطة لأقرب مركز ثم نحسب المراكز الجديدة كمتوسطات، حتى الاستقرار.
@ stdin
10 20
@ steps
- في كل تكرار: نمر على النقاط؛ إذا كانت `|spend - c1| <= |spend - c2|` تنتمي للمجموعة 1.
- نجمع مجموع وعدد كل مجموعة، ثم المركز الجديد = المتوسط.
- نتوقف عندما لا يتغير المركزان (أو بعد 20 تكرارًا).
@ flow
in: c1, c2
do: changed = 1 ; it = 0
while: changed && it < 20
  do: s1 = s2 = n1 = n2 = 0
  for: customer = 0 ; customer < 20 ; customer++
    do: spend = (customer*37) % 50 + (customer%2)*60
    if: |spend - c1| <= |spend - c2|
      do: s1 += spend ; n1++
    else:
      do: s2 += spend ; n2++
  do: m1 = s1/n1 ; m2 = s2/n2
  do: changed = (m1 != c1 || m2 != c2)
  do: c1 = m1 ; c2 = m2 ; it++
out: c1, c2, it
@ code
#include <stdio.h>

int main(void) {
    double c1, c2, m1, m2, s1, s2, spend, d1, d2;
    int customer, n1, n2, it = 0, changed = 1;
    scanf("%lf %lf", &c1, &c2);           // المركزان الابتدائيان
    while (changed && it < 20) {
        s1 = s2 = 0; n1 = n2 = 0;
        for (customer = 0; customer < 20; customer++) {
            spend = (customer * 37) % 50 + (customer % 2) * 60;   // إنفاق الزبون customer
            d1 = spend - c1; if (d1 < 0) d1 = -d1;  // المسافة إلى c1
            d2 = spend - c2; if (d2 < 0) d2 = -d2;  // المسافة إلى c2
            if (d1 <= d2) { s1 += spend; n1++; }    // أقرب إلى c1
            else          { s2 += spend; n2++; }
        }
        m1 = (n1 > 0) ? s1 / n1 : c1;   // المركز الجديد = المتوسط
        m2 = (n2 > 0) ? s2 / n2 : c2;
        changed = (m1 != c1 || m2 != c2);
        c1 = m1; c2 = m2;
        it++;
        printf("Iter %d: c1 = %.2f (%d), c2 = %.2f (%d)\n", it, c1, n1, c2, n2);
    }
    printf("Converged after %d iterations\n", it);
    return 0;
}

title: الانحدار بالنزول التدريجي
level: hard
domain: ds
@ statement
بدل الصيغة المغلقة، ندرب نموذج `target = weight feature + bias` بخوارزمية **النزول التدريجي** (Gradient Descent). البيانات: `feature(index) = index` و`target(index) = 3i + 7 + ((index * 7) % 5 - 2)` لـ `index` من 0 إلى 9. في كل حقبة نحسب المشتقتين `dw = (2/nbPoints) Σ (ŷ - target) feature` و`db = (2/nbPoints) Σ (ŷ - target)` ثم `weight -= lr * dw` و`bias -= lr * db`. اكتب برنامجًا يدرب النموذج ويعرض الخطأ.
@ stdin
0.01 3000
@ steps
- نهيئ `weight = 0` و`bias = 0`.
- لكل حقبة: نمر على النقاط ونجمع التدرجين والخطأ التربيعي.
- نحدّث المعاملين بمعدل التعلم `lr`.
- نعرض التقدم كل 500 حقبة.
@ flow
in: lr, epochs
do: weight = 0 ; bias = 0
for: epoch = 1 ; epoch <= epochs ; epoch++
  do: dw = 0 ; db = 0 ; mse = 0
  for: index = 0 ; index < 10 ; index++
    do: err = weight*feature(index) + bias - target(index)
    do: dw += err*feature ; db += err ; mse += err*err
  do: weight -= lr * 2*dw/nbPoints ; bias -= lr * 2*db/nbPoints
out: weight, bias, mse / nbPoints
@ code
#include <stdio.h>

int main(void) {
    double lr, weight = 0, bias = 0, dw, db, mse, feature, target, err;
    int epochs, epoch, index, nbPoints = 10;
    scanf("%lf %d", &lr, &epochs);
    for (epoch = 1; epoch <= epochs; epoch++) {
        dw = db = mse = 0;
        for (index = 0; index < nbPoints; index++) {
            feature = index;
            target = 3 * index + 7 + ((index * 7) % 5 - 2);  // بيانات مع ضجيج
            err = weight * feature + bias - target;                // خطأ التنبؤ
            dw += err * feature;                      // مساهمة النقطة في التدرج
            db += err;
            mse += err * err;
        }
        weight -= lr * 2 * dw / nbPoints;     // خطوة في عكس اتجاه التدرج
        bias -= lr * 2 * db / nbPoints;
        if (epoch % 500 == 0)
            printf("Epoch %4d: weight = %.4f, bias = %.4f, MSE = %.4f\n", epoch, weight, bias, mse / nbPoints);
    }
    return 0;
}

title: التحقق من رقم البطاقة بخوارزمية Luhn
level: hard
domain: ec
@ statement
قبل إرسال الدفع للبنك نتحقق من رقم البطاقة بخوارزمية **Luhn**: من اليمين، نضاعف رقمًا من كل اثنين (الثاني، الرابع، ...)، وإذا تجاوز الناتج 9 نطرح 9، ثم نجمع كل الأرقام؛ الرقم صالح إذا كان المجموع يقبل القسمة على 10. اكتب البرنامج لرقم من 16 خانة.
@ stdin
4539578763621486
@ steps
- نقرأ الرقم في `unsigned long long`.
- حلقة: `digit = number % 10` ثم `number /= 10`، مع موضع `pos` يبدأ من 1 من اليمين.
- إذا كان `pos` زوجيًا: `digit = 2d` ثم `digit -= 9` إذا تجاوز 9.
- نجمع، ونتحقق من `sum % 10 == 0`.
@ flow
in: number
do: sum = 0 ; pos = 1
while: number > 0
  do: digit = number % 10 ; number = number / 10
  if: pos % 2 == 0
    do: digit = 2 * digit
    if: digit > 9
      do: digit = digit - 9
  do: sum += digit ; pos++
if: sum % 10 == 0
  out: `"valid"`
else:
  out: `"invalid"`
@ code
#include <stdio.h>

int main(void) {
    unsigned long long number;
    int digit, sum = 0, pos = 1;
    scanf("%llu", &number);
    while (number > 0) {
        digit = number % 10;               // نقرأ الأرقام من اليمين
        number = number / 10;
        if (pos % 2 == 0) {       // رقم من كل اثنين
            digit = 2 * digit;
            if (digit > 9)
                digit = digit - 9;        // = مجموع رقمي الناتج
        }
        sum += digit;
        pos++;
    }
    printf("Luhn sum = %d\n", sum);
    if (sum % 10 == 0)
        printf("Card number is valid\n");
    else
        printf("Card number is INVALID\n");
    return 0;
}

- عدد الأعمدة: `c = (number + r - 1) / r`، وإذا لم يكن مربعًا كاملًا نستعمل `r + 1` أسطر.
@ flow

do: lo = 0 ; hi = number ; ans = 0

  do: mid = lo + (hi - lo) / 2
  if: mid * mid <= number
    do: ans = mid ; lo = mid + 1
  else:
    do: hi = mid - 1
out: ans, ans * ans == number
@ code
#include <stdio.h>

int main(void) {
    long long number, lo, hi, mid, ans = 0;
    scanf("%lld", &number);
    lo = 0;
    hi = (number < 3000000000LL) ? number : 3000000000LL;  // حد أعلى آمن للمربع
    while (lo <= hi) {
        mid = lo + (hi - lo) / 2;     // يتجنب تجاوز السعة عند الجمع
        if (mid * mid <= number) {
            ans = mid;                // مرشح صالح، نبحث عن أكبر
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    printf("isqrt(%lld) = %lld\n", number, ans);
    if (ans * ans == number)
        printf("Perfect square: grid %lld x %lld\n", ans, ans);
    else
        printf("Not a square: grid %lld x %lld\n", ans + 1, (number + ans) / (ans + 1));
    return 0;
}

title: أفضل يوم للشراء والبيع

@ statement
يتابع تاجر سعر منتج يوميًا لمدة `nbDays` يومًا ويريد **الشراء مرة والبيع مرة** لاحقًا لتحقيق أكبر ربح. اكتب برنامجًا يحل المسألة في **مرور واحد**: نحتفظ بأدنى سعر رأيناه حتى الآن ويوم حدوثه.
@ stdin

320 280 300 250 310 390 360 240 330 370
@ steps
- `minP` = أدنى سعر حتى اليوم، و`minDay` يومه.
- كل يوم: الربح الممكن إذا بعنا اليوم هو `price - minP`.

@ flow

  in: price
  if: price - minP > best

  if: price < minP

#include <stdio.h>

    int nbDays, day, minDay = 1, buy = 0, sell = 0;
    double price, minP, best = 0;
    scanf("%d %lf", &nbDays, &price);
    minP = price;
    for (day = 2; day <= nbDays; day++) {
        scanf("%lf", &price);
