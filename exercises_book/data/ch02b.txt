يستعمل موظف المخزن آلة حاسبة بسيطة: يقرأ عددين وعاملًا (`+` أو `-` أو `*` أو `/` أو `%` للنسبة المئوية: a% من b). اكتب البرنامج باستعمال `switch` مع منع القسمة على صفر.
@ stdin
15 % 8400
@ steps
- نقرأ `left` ثم العامل `op` ثم `right`.
- لكل عامل حالة في `switch`.
- في حالة `/` نتحقق أن `right != 0`.
- `%` تعطي `left * right / 100`.
@ flow
in: left, op, right
if: op == '/' && right == 0
  out: `"division by zero"`
else:
  do: حسب op: result = left+right أو left-right أو left*right أو left/right أو left*right/100
  out: result
@ code
#include <stdio.h>

int main(void) {
    double left, right, result = 0;
    char op;
    int ok = 1;                       // 1 إذا كانت العملية صالحة
    scanf("%lf %c %lf", &left, &op, &right);
    switch (op) {
        case '+': result = left + right; break;
        case '-': result = left - right; break;
        case '*': result = left * right; break;
        case '/':
            if (right == 0) ok = 0;       // لا نقسم على صفر
            else result = left / right;
            break;
        case '%': result = left * right / 100; break;   // left بالمئة من right
        default: ok = 0;
    }
    if (ok)
        printf("%.2f %c %.2f = %.2f\n", left, op, right, result);
    else
        printf("Error: invalid operation\n");
    return 0;
}

title: السعر الأمثل
level: medium
domain: ds
@ statement
قدّر محلل أن الطلب يتبع `Q = demandMax - slope*price`. رقم الأعمال `revenue = price * (demandMax - slope*price)` يبلغ أقصاه عند `price* = demandMax / (2b)`. لكن السعر يجب أن يبقى بين `pmin` و`pmax`. اكتب برنامجًا يحسب السعر الأمثل المسموح ورقم الأعمال الموافق.
@ stdin
5000 2 1500 3000
@ steps
- `price = demandMax / (2 * slope)`.
- إذا كان `price < pmin` نأخذ `pmin`، وإذا كان `price > pmax` نأخذ `pmax`.
- `revenue = price * (demandMax - slope * price)`.
@ flow
in: demandMax, slope, pmin, pmax
do: price = demandMax / (2 * slope)
if: price < pmin
  do: price = pmin
else:
  if: price > pmax
    do: price = pmax
do: revenue = price * (demandMax - slope * price)
out: price, revenue
@ code
#include <stdio.h>

int main(void) {
    double demandMax, slope, pmin, pmax, price, revenue;
    scanf("%lf %lf %lf %lf", &demandMax, &slope, &pmin, &pmax);
    price = demandMax / (2 * slope);                  // قمة القطع المكافئ
    printf("Unconstrained optimum = %.2f DA\n", price);
    if (price < pmin)
        price = pmin;                     // نحصر السعر في المجال المسموح
    else if (price > pmax)
        price = pmax;
    revenue = price * (demandMax - slope * price);
    printf("Chosen price = %.2f DA\n", price);
    printf("Revenue = %.2f DA\n", revenue);
    return 0;
}

title: توازن العرض والطلب
level: hard
domain: ds
@ statement
في سوق منتج: الطلب `Qd = demandBase - demandSlope*price` والعرض `Qs = supplyBase + supplySlope*price`. **سعر التوازن** يحقق `Qd = Qs` أي `price* = (demandBase - supplyBase) / (demandSlope + supplySlope)`. تفرض الدولة أحيانًا **سعرًا أدنى** `floor`. اكتب برنامجًا يحسب التوازن؛ وإذا كان السعر الأدنى أعلى من `price*` يُباع بالسعر الأدنى ويظهر **فائض** `Qs - Qd`. تحقق أيضًا أن التوازن ممكن (`price* > 0` و`Q* > 0`).
@ stdin
1000 4 100 2
180
@ steps
- `price = (demandBase - supplyBase) / (demandSlope + supplySlope)` و`quantity = demandBase - demandSlope * price`.
- إذا كان `price <= 0` أو `quantity <= 0`: لا يوجد توازن ذو معنى.
- إذا كان `floor > price`: نحسب `Qd` و`Qs` عند `floor` والفائض.
- وإلا السعر الأدنى غير مؤثر.
@ flow
in: demandBase, demandSlope, supplyBase, supplySlope, floor
do: price = (demandBase - supplyBase) / (demandSlope + supplySlope)
do: quantity = demandBase - demandSlope * price
if: price <= 0 || quantity <= 0
  out: `"no equilibrium"`
else:
  out: price, quantity
  if: floor > price
    do: qd = demandBase - demandSlope*floor ; qs = supplyBase + supplySlope*floor
    out: qs - qd
  else:
    out: `"floor not binding"`
@ code
#include <stdio.h>

int main(void) {
    double demandBase, demandSlope, supplyBase, supplySlope, floor_p, price, quantity, qd, qs;
    scanf("%lf %lf %lf %lf", &demandBase, &demandSlope, &supplyBase, &supplySlope);
    scanf("%lf", &floor_p);               // السعر الأدنى المفروض
    price = (demandBase - supplyBase) / (demandSlope + supplySlope);                // من demandBase - demandSlope*price = supplyBase + supplySlope*price
    quantity = demandBase - demandSlope * price;
    if (price <= 0 || quantity <= 0) {
        printf("No meaningful equilibrium\n");
    } else {
        printf("Equilibrium: p* = %.2f DA, q* = %.2f units\n", price, quantity);
        if (floor_p > price) {                // السعر الأدنى مؤثر
            qd = demandBase - demandSlope * floor_p;         // الطلب ينخفض
            qs = supplyBase + supplySlope * floor_p;         // العرض يرتفع
            printf("At floor %.2f: demand %.2f, supply %.2f\n", floor_p, qd, qs);
            printf("Surplus = %.2f units\n", qs - qd);
        } else {
            printf("Price floor not binding\n");
        }
    }
    return 0;
}
