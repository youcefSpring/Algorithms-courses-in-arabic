level: hard
domain: ec
@ statement
اكتب برنامجًا يرتب أسعار 12 منتجًا بخوارزمية **الترتيب السريع** (Quick Sort) دون استعمال الدوال العودية: نستعمل **مكدسًا يدويًا** (جدولين `stackLow` و`stackHigh`) لحفظ الأجزاء التي تنتظر الترتيب. التقسيم بطريقة Lomuto مع آخر عنصر كمحور.
@ steps
- ندفع المجال `[0, NB-1]` في المكدس.
- ما دام المكدس غير فارغ: نسحب مجالًا `[low, high]`.
- التقسيم: كل عنصر أصغر من المحور ينقل إلى اليسار، ثم يوضع المحور في مكانه `pivotPos`.
- ندفع الجزأين `[low, pivotPos-1]` و`[pivotPos+1, high]` إذا كان طولهما أكبر من 1.
@ flow
do: push [0, NB-1]
while: top > 0
  do: pop low, high
  do: pivot = prices[high] ; store = low
  for: scan = low ; scan < high ; scan++
    if: prices[scan] < pivot
      do: تبديل prices[scan] و prices[store] ; store++
  do: تبديل prices[store] و prices[high]
  if: store - 1 > low
    do: push [low, store-1]
  if: store + 1 < high
    do: push [store+1, high]
out: prices
@ code
#include <stdio.h>

#define NB 12

int main(void) {
    int prices[NB] = {890, 120, 450, 3000, 75, 640, 1200, 300, 999, 15, 2200, 640};
    int stackLow[NB], stackHigh[NB], top = 0;
    int low, high, pivot, store, scan, tmp, index;
    stackLow[top] = 0; stackHigh[top] = NB - 1; top++;   // المجال الكامل
    while (top > 0) {
        top--;                                // نسحب مجالًا
        low = stackLow[top];
        high = stackHigh[top];
        pivot = prices[high];                 // المحور: آخر عنصر
        store = low;                          // حد منطقة "الأصغر من المحور"
        for (scan = low; scan < high; scan++) {
            if (prices[scan] < pivot) {
                tmp = prices[scan]; prices[scan] = prices[store]; prices[store] = tmp;
                store++;
            }
        }
        tmp = prices[store]; prices[store] = prices[high]; prices[high] = tmp;
        // المحور الآن في مكانه النهائي store
        if (store - 1 > low)  { stackLow[top] = low;       stackHigh[top] = store - 1; top++; }
        if (store + 1 < high) { stackLow[top] = store + 1; stackHigh[top] = high;      top++; }
    }
    for (index = 0; index < NB; index++)
        printf("%d ", prices[index]);
    printf("\n");
    return 0;
}

@ code
#include <stdio.h>

#define NB 10

int main(void) {

    int buffer[NB];
    int width, left, mid, right, posA, posB, out, index;
    for (width = 1; width < NB; width *= 2) {         // طول الأجزاء المرتبة

            while (posB < right) buffer[out++] = times[posB++];
        }
        for (index = 0; index < NB; index++)
            times[index] = buffer[index];
        printf("width %d:", width);
        for (index = 0; index < NB; index++)

title: تجميع الزبائن إلى ثلاث فئات
level: hard
domain: ds
@ statement
اكتب برنامجًا يطبق **K-Means** بثلاث مجموعات على إنفاق 15 زبونًا مخزن في جدول: المراكز الأولية هي أصغر قيمة، الوسط، وأكبر قيمة. نكرر الإسناد وإعادة الحساب حتى لا يتغير أي إسناد، ونعرض المراكز وأعضاء كل مجموعة.
@ steps
- `group[index]` رقم مجموعة كل زبون (يبدأ بـ -1).
- الإسناد: أقرب مركز بالقيمة المطلقة للفرق.
- `changed` يعد الزبائن الذين غيروا مجموعتهم؛ نتوقف عندما يساوي 0.
- إعادة الحساب: كل مركز = متوسط أعضائه.
@ flow
do: centers = {min, middle, max} ; group[] = -1
dowhile: changed > 0
  do: changed = 0
  for: index = 0 ; index < NB ; index++
    do: closest = أقرب مركز إلى spend[index]
    if: closest != group[index]
      do: group[index] = closest ; changed++
  do: كل مركز = متوسط أعضائه
out: centers, group
@ code
#include <stdio.h>

#define NB 15
#define NB_GROUPS 3

int main(void) {
    double spend[NB] = {12, 15, 90, 14, 52, 48, 95, 11, 55, 100, 47, 13, 88, 50, 92};
    double centers[NB_GROUPS] = {11, 50, 100};    // أصغر، وسط، أكبر
    double sum[NB_GROUPS], gap, bestGap;
    int group[NB], members[NB_GROUPS];
    int index, cluster, closest, changed, iteration = 0;
    for (index = 0; index < NB; index++)
        group[index] = -1;                // لا مجموعة بعد
    do {
        changed = 0;
        for (index = 0; index < NB; index++) {      // مرحلة الإسناد
            closest = 0;
            bestGap = -1;
            for (cluster = 0; cluster < NB_GROUPS; cluster++) {
                gap = spend[index] - centers[cluster];
                if (gap < 0) gap = -gap;
                if (bestGap < 0 || gap < bestGap) { bestGap = gap; closest = cluster; }
            }
            if (closest != group[index]) { group[index] = closest; changed++; }
        }
        for (cluster = 0; cluster < NB_GROUPS; cluster++) { sum[cluster] = 0; members[cluster] = 0; }
        for (index = 0; index < NB; index++) {      // مرحلة إعادة الحساب
            sum[group[index]] += spend[index];
            members[group[index]]++;
        }
        for (cluster = 0; cluster < NB_GROUPS; cluster++)
            if (members[cluster] > 0)
                centers[cluster] = sum[cluster] / members[cluster];
        iteration++;
    } while (changed > 0);
    printf("Converged in %d iterations\n", iteration);
    for (cluster = 0; cluster < NB_GROUPS; cluster++) {
        printf("Group %d (center %.2f):", cluster, centers[cluster]);
        for (index = 0; index < NB; index++)
            if (group[index] == cluster)
                printf(" %.0f", spend[index]);
        printf("\n");
    }
    return 0;
}

#define BUDGET 20

#include <stdio.h>

#define NB_B 10
#define NB_P 6

int main(void) {

    int basket, prod, first, second, pairCount, mask;
    for (basket = 0; basket < NB_B; basket++)
        for (prod = 0; prod < NB_P; prod++)
            if ((baskets[basket] >> prod) & 1)    // هل البت prod يساوي 1؟
                single[prod]++;

            pairCount = 0;

                    pairCount++;
            if (pairCount * 100 >= 30 * NB_B)
                printf("{%d,%d}: support %d%%, confidence %d->%d = %.2f\n",

                       (double)pairCount / single[first]);

title: معامل جيني لتركز الإنفاق

@ statement
يقيس **معامل جيني** مدى تركز الإنفاق عند قلة من الزبائن (0 = توزيع متساوٍ، 1 = زبون واحد ينفق كل شيء). بعد ترتيب الإنفاق تصاعديًا: `G = (2 Σ i·x_i) / (n Σ x_i) - (n + 1) / n` حيث `i` من 1 إلى n. اكتب برنامجًا يحسبه، ويحسب أيضًا حصة أكبر 20% من الزبائن.

    int rank, scan;

        key = spend[rank];
        for (scan = rank - 1; scan >= 0 && spend[scan] > key; scan--)
            spend[scan + 1] = spend[scan];
        spend[scan + 1] = key;

    for (rank = 0; rank < NB; rank++) {
        weighted += (rank + 1) * spend[rank];     // الرتبة تبدأ من 1
        total += spend[rank];

    for (rank = NB - NB / 5; rank < NB; rank++)   // أكبر 20%
        top += spend[rank];
    printf("Gini = %.3f\n", gini);
    printf("Top 20%% customers = %.1f%% of revenue\n", top * 100 / total);

}

@ statement
يريد مسؤول الإعلانات تشغيل حملة في **أيام متتالية**، وتكلفة كل يوم معروفة. اكتب برنامجًا يجد **أطول** سلسلة أيام متتالية مجموع تكاليفها لا يتجاوز الميزانية، بطريقة **النافذة المنزلقة** في `O(n)`.
@ stdin
1000
@ steps
- مؤشرا النافذة `left` و`right`، ومجموعها `windowCost`.
- نوسع النافذة يمينًا بإضافة `cost[right]`.
- ما دام المجموع يتجاوز الميزانية نقلصها من اليسار.
- نحفظ أطول نافذة صالحة.
@ flow
in: budget
do: left = 0 ; windowCost = 0 ; bestLen = 0
for: right = 0 ; right < NB ; right++
  do: windowCost += cost[right]
  while: windowCost > budget
    do: windowCost -= cost[left] ; left++
  if: right - left + 1 > bestLen
    do: bestLen = right - left + 1 ; bestLeft = left
out: bestLen, bestLeft
@ code
#include <stdio.h>

#define NB 14

int main(void) {
    int cost[NB] = {300, 150, 200, 500, 100, 120, 90, 400, 80, 60, 250, 700, 50, 100};
    int budget, left = 0, right, windowCost = 0, bestLen = 0, bestLeft = 0, day;
    scanf("%d", &budget);
    for (right = 0; right < NB; right++) {
        windowCost += cost[right];        // نضيف يومًا من اليمين
        while (windowCost > budget) {     // تجاوزنا: نحذف من اليسار
            windowCost -= cost[left];
            left++;
        }
        if (right - left + 1 > bestLen) {
            bestLen = right - left + 1;
            bestLeft = left;
        }
    }
    printf("Longest campaign: %d days (day %d to %d):",
           bestLen, bestLeft + 1, bestLeft + bestLen);
    windowCost = 0;
    for (day = bestLeft; day < bestLeft + bestLen; day++) {
        printf(" %d", cost[day]);
        windowCost += cost[day];
    }
    printf(" = %d DA\n", windowCost);
    return 0;
}
