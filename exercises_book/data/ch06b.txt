title: توازن الأقواس في ملف إعدادات
level: medium
domain: ds
@ statement
ملف إعدادات المتجر بصيغة شبيهة بـ JSON. اكتب برنامجًا يتحقق من **توازن الأقواس** `()` و`[]` و`{}` باستعمال **مكدس** (جدول حروف)، ويتجاهل ما بين علامتي الاقتباس.
@ steps
- قوس فاتح: ندفعه في المكدس.
- قوس مغلق: يجب أن يطابق قمة المكدس، ثم نسحبها.
- في النهاية يجب أن يكون المكدس فارغًا.
@ flow
do: top = 0 ; ok = 1
for: pos = 0 ; text[pos] != '\0' && ok ; pos++
  if: داخل اقتباس
    do: تجاهل
  else:
    if: قوس فاتح
      do: stack[top++] = text[pos]
    else:
      if: قوس مغلق
        if: top == 0 || لا يطابق stack[top-1]
          do: ok = 0
        else:
          do: top--
out: ok && top == 0
@ code
#include <stdio.h>

int main(void) {
    char text[] = "{\"shop\": {\"name\": \"Dz(Store\", \"tags\": [\"tech\", \"home\"]}, \"open\": [8, 20]}";
    char stack[50], ch, expected;
    int pos, top = 0, ok = 1, inQuote = 0;
    for (pos = 0; text[pos] != '\0' && ok; pos++) {
        ch = text[pos];
        if (ch == '"') { inQuote = !inQuote; continue; }
        if (inQuote) continue;                // الأقواس داخل النص لا تُحسب
        if (ch == '(' || ch == '[' || ch == '{') {
            stack[top++] = ch;                // دفع
        } else if (ch == ')' || ch == ']' || ch == '}') {
            expected = (ch == ')') ? '(' : (ch == ']') ? '[' : '{';
            if (top == 0 || stack[top - 1] != expected)
                ok = 0;
            else
                top--;                        // سحب
        }
    }
    if (ok && top == 0)
        printf("Brackets are balanced\n");
    else
        printf("Unbalanced at position %d\n", pos - 1);
    return 0;
}

title: لون المنتج من الشفرة الست عشرية
level: medium
domain: ec
@ statement
ألوان المنتجات مخزنة بصيغة الويب `#RRGGBB`. اكتب برنامجًا يحول الشفرة إلى ثلاث قيم عشرية (أحمر، أخضر، أزرق) بين 0 و255، ويحسب **سطوعها** `0.299R + 0.587G + 0.114B` ليختار نصًا أبيض أو أسود فوقها.
@ stdin
#FF8800
@ steps
- قيمة رقم ست عشري: `0-9` أو `A-F` (أو `a-f`).
- كل لون رقمان: `16 * high + low`.
- السطوع > 128: نص أسود، وإلا أبيض.
@ flow
in: color
for: part = 0 ; part < 3 ; part++
  do: high = قيمة color[1 + 2*part] ; low = قيمة color[2 + 2*part]
  do: rgb[part] = 16 * high + low
do: light = 0.299*R + 0.587*G + 0.114*B
out: rgb, light
@ code
#include <stdio.h>

int main(void) {
    char color[10], ch;
    int rgb[3], part, digit, half, value;
    double light;
    scanf("%9s", color);
    for (part = 0; part < 3; part++) {
        value = 0;
        for (half = 0; half < 2; half++) {    // رقمان لكل لون
            ch = color[1 + 2 * part + half];
            if (ch >= '0' && ch <= '9')      digit = ch - '0';
            else if (ch >= 'A' && ch <= 'F') digit = ch - 'A' + 10;
            else                             digit = ch - 'a' + 10;
            value = value * 16 + digit;
        }
        rgb[part] = value;
    }
    light = 0.299 * rgb[0] + 0.587 * rgb[1] + 0.114 * rgb[2];
    printf("%s -> R=%d G=%d B=%d\n", color, rgb[0], rgb[1], rgb[2]);
    printf("Brightness %.1f -> use %s text\n", light, light > 128 ? "black" : "white");
    return 0;
}

@ steps

- نقارن الحروف موضعًا بموضع ونعد الاختلافات.
@ flow
in: codeA, codeB

    out: pos

#include <stdio.h>

int main(void) {
    char codeA[30], codeB[30];
    int pos, lengthA = 0, lengthB = 0, distance = 0;
    scanf("%29s %29s", codeA, codeB);
    while (codeA[lengthA] != '\0') lengthA++;
    while (codeB[lengthB] != '\0') lengthB++;
    if (lengthA != lengthB) {
        printf("Different lengths: not comparable\n");
        return 0;
    }
    for (pos = 0; pos < lengthA; pos++)
        if (codeA[pos] != codeB[pos]) {
            distance++;
            printf("Position %d: %c vs %c\n", pos, codeA[pos], codeB[pos]);
        }
    printf("Hamming distance = %d%s\n", distance,
           distance == 1 ? " -> probable typo" : "");
